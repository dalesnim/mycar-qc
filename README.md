# MyCar — контроль качества кузова

## Что умеет

- карта кузова из SVG, кликаешь по ней и появляеться метка дефекта
- карточка дефекта: тип, зона, серьёзность, комментарий
- без типа и зоны дефект не сохранится, покажет ошибки
- список дефектов с фильтрами по типу и статусу, работает вместе с картой
- статусы: new → in_repair → resolved / rejected, назад вернуть нельзя
- сводка сколько дефектов в каком статусе
- сервер на Express, дефекты хранятся на нём а не в браузере
- всё сохраняется в `server/data.json`, перезапустил сервер — данные на месте
- отчёт PDI по кузову: таблица дефектов и итог годен / не годен к выдаче

## Стек

Фронт: Vue 3 + TypeScript + Vite. Сервер: Node + Express. Тесты: Vitest.

## Структура

- `src/type.ts` — типы (Defect, Status, Severity)
- `src/store.ts` — состояние и запросы к API
- `src/validation.ts` — validateDefect
- `src/fsm.ts` — переходы статусов и canTransition
- `src/summary.ts` — подсчёт сводки
- `src/components/` — CarMap, DefectCard, DefectList, StatusSummary
- `src/__tests__/` — тесты фронта
- `server/` — API-сервер (app, db, rules, storage, report)
- `server/__tests__/` — тесты сервера

## Как запустить

Нужно два терминала: один для сервера, второй для фронта.

```sh
npm install
npm run server
```

и во втором терминале:

```sh
npm run dev
```

Фронт откроется на http://localhost:5173, сервер на http://localhost:3000.

## Деплой

Проект доступен на Vercel: https://mycar-qc.vercel.app

Но там только фронт, сервер на верселе не крутится, поэтому дефекты там
не сохраняются. Полная версия с сервером запускается локально как написано выше.

## Тесты

```sh
npm run test:unit
```

Тесты фронта: FSM, валидация, сводка. Тесты сервера: создание/изменение/удаление,
валидация на сервере, сохранение и чтение после перезапуска, отчёт PDI.
